# WhatsApp Message Automation & Scheduler

A Python-based WhatsApp automation project that allows users to schedule messages for a specific date and time.

## Features

- Send WhatsApp messages using Twilio
- Schedule messages for a specific date and time
- Take recipient details and message as user input
- Calculate the delay between current and scheduled time
- Automatically wait until the scheduled time
- Handle errors using exception handling

## Technologies Used

- Python
- Twilio API
- datetime
- time
- os
